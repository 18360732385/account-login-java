# 需求：登出 + 改密（需旧密码）

## 背景
在既有 JWT 登录（`POST /api/auth/login`、`GET /api/me`）之上，增加可断言的服务端登出与改密。

## 功能
1. **登出** `POST /api/auth/logout`（Bearer 必填）
   - 将当前 token 的 `jti` 写入服务端 denylist
   - 成功后同一 token 访问受保护接口应 401
2. **改密** `POST /api/auth/change-password`（Bearer 必填）
   - Body：`{ "oldPassword", "newPassword" }`
   - 校验旧密码；成功后递增用户 `tokenVersion` 并吊销当前 jti
   - 旧 token 失效；须用新密码重新登录
3. **CORS**：提供 `CorsConfigurationSource`（允许 `http://localhost:5173`），与前端 Vite proxy 并存

## 非目标
- 持久化用户库 / 刷新令牌 / 多设备会话管理 UI

## 验收
