# 产品需求：账号登录

| 项 | 内容 |
|---|---|
| 主题 | 账号登录 API |
| 仓库 | account-login-java |
| 日期 | 2026-09-21 |
| 状态 | 已实现（本轮 Full 路径交付） |

## 1. 背景

提供一套最小可用的账号登录后端能力，供演示 / 联调使用。用户使用用户名与密码换取 JWT，再用 Token 访问受保护资源。

## 2. 目标用户

- 后端/全栈开发者：本地快速跑通登录与鉴权
- 前端联调人员：用 curl 或 HTTP 客户端换 Token 调 `/api/me`

## 3. 功能范围

### 3.1 登录

- **接口**：`POST /api/auth/login`
- **请求体**：`{"username":"...","password":"..."}`
- **成功**：HTTP 200，返回 `accessToken`、`tokenType=Bearer`、`expiresInMs`
- **失败**：用户名不存在或密码错误 → HTTP 401，文案「用户名或密码错误」（不区分哪种，防枚举）

### 3.2 当前用户

- **接口**：`GET /api/me`
- **鉴权**：`Authorization: Bearer <token>`
- **成功**：返回 `username`、`displayName`
- **未带 Token / Token 无效**：HTTP 401

### 3.3 演示账号

| 用户名 | 密码 | 显示名 |
|---|---|---|
| demo | demo123 | 演示用户 |
| admin | admin123 | 管理员 |

账号存于内存（启动时 BCrypt 哈希），不依赖外部数据库。

## 4. 非功能

- Spring Boot 3.x + Java 17（源/目标）+ Spring Security + JWT（HS256）
- 无状态会话（STATELESS）
- 至少覆盖：登录成功、登录失败、`/api/me` 需鉴权、带 Token 访问 `/api/me`

## 5. 非目标（本轮不做）

- 注册 / 找回密码 / 刷新 Token / 登出黑名单
- 持久化用户表、OAuth2、前端页面
- 多租户、RBAC 细粒度权限

## 6. 验收标准

1. `mvn -q test` 全部通过
2. 本地启动后可用 curl 完成登录 → 带 Token 访问 `/api/me`
3. 无 Token 访问 `/api/me` 返回 401
