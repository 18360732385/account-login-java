# 设计笔记 — 登出+改密（java）

## 方案
1. **登出**：JWT 带 jti；`TokenDenylist` 内存吊销；过滤器校验 denylist
2. **改密**：校验旧密码 → 更新哈希 → `tokenVersion++`（旧 JWT tv 不匹配即失效）+ 吊销当前 jti
3. **CORS**：显式 `CorsConfigurationSource` Bean（修复仅 `cors(withDefaults)` 无源问题）

## 跨仓顺序
API Spec 先定稿 → web 写消费契约。CORS 由后端拥有 Bean；proxy 由前端拥有——双轨并存记入 `integration_ready`。

## 风险
演示账号内存改密污染共享用户 → 测试 `@AfterEach resetCredentials`（O15）。
