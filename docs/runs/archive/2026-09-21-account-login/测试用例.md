# 测试用例 — 账号登录 API（F）

| ID | 场景 | 步骤 | 期望 | 类型 |
|---|---|---|---|---|
| TC01 | 登录成功 | POST /api/auth/login 合法 demo 账号 | 200；有 accessToken；tokenType=Bearer | 集成 |
| TC02 | 登录失败（错密） | POST 错误密码 | 401；message=用户名或密码错误 | 集成 |
| TC03 | /api/me 无 Token | GET /api/me 不带 Authorization | 401；code=UNAUTHORIZED | 集成 |
| TC04 | /api/me 有 Token | 先登录拿 Token，再 GET /api/me | 200；username/displayName 正确 | 集成 |

映射：`AuthApiIntegrationTest` 四个 `@Test` 方法一一对应。
