# 设计笔记 — 账号登录 API

> 厨师声音（controller_proxy）；设计确认闸：`authorized_by: user_task_2026-09-21`

## 共享理解（grill 摘要）

1. 交付物是 **后端 API**，不是前端页面 → proto 默认跳过
2. 用户存储用 **内存演示账号**（等价轻量 H2；本轮选纯内存更简单）
3. 鉴权方案：**Spring Security + 自签 JWT（HS256）**，无状态
4. 对外契约固定：`POST /api/auth/login`、`GET /api/me`
5. 验收以集成测试 + `mvn test` 为准

## 架构草图

```
Client → AuthController
            ├─ POST /api/auth/login → AuthService → DemoUserStore + JwtService
            └─ GET  /api/me         → AuthService（需 JwtAuthenticationFilter 注入 Authentication）
SecurityFilterChain: permit login；其余 authenticated；401 JSON
```

## 关键决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 用户仓 | 内存 ConcurrentHashMap | 演示足够；无 DB 依赖 |
| Token | jjwt 0.12 + HS256 | 常见、可测 |
| 密码 | BCrypt | Spring Security 默认推荐 |
| 错误信息 | 登录失败统一文案 | 防用户名枚举 |
| 包结构 | controller / service / security / dto / config | 小项目清晰分层 |

## 风险

- 演示密钥写在 `application.yml` → README 标明勿用于生产
- 无刷新 Token → 过期后需重新登录（本轮非目标）
